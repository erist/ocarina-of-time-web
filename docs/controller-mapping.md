# 버튼·음계·운지 확인 — 2026-11-13

## 노멀 조작의 기본 버튼

| 게임 버튼 | 기본 실음 | 앱 음 식별자 |
| --- | --- | --- |
| L | 레 · D5 | D |
| R | 파 · F5 | F |
| A | 라 · A5 | A |
| Y | 시 · B5 | B |
| X | 높은 레 · D6 | d |
| B | 연주 종료·정지 | 음높이 없음 |

기본 음은 다섯 개다. L/R/X/Y/A/B 여섯 표기를 사용할 때 B는 여섯 번째 음으로 만들지 않고 정지 동작으로 사용한다. 대문자 음 식별자 `B`는 음악의 시(B5), 컨트롤러 버튼 `B`는 정지이므로 코드에서 두 의미를 구분한다.

확인한 Nintendo 원본 화면:

- [공식 오카리나 설명](https://www.nintendo.com/jp/games/switch2/aa9ja/modal/ocarina.html)의 [젤다의 자장가 화면](https://www.nintendo.com/jp/games/switch2/aa9ja/assets/img/modal_ocarina/melody_thumb_01.webp): 오선 위 `Y X A Y X A`를 직접 확인. 각각 시·높은 레·라 위치다.
- [공식 수수께끼 페이지](https://www.nintendo.com/jp/games/switch2/aa9ja/dungeon/index.html)의 [시간의 노래 화면](https://www.nintendo.com/jp/games/switch2/aa9ja/assets/img/dungeon/item_ocarina_thumb.webp): 오선 위 `A L R A L R`를 직접 확인. 각각 라·레·파 위치다.
- [공식 악보 페이지](https://www.nintendo.com/jp/games/switch2/aa9ja/melody/index.html)의 [음성 입력 화면](https://www.nintendo.com/jp/games/switch2/aa9ja/assets/img/melody/voice_thumb.webp): 하단 소리내기 버튼 `L R Y X A`, 종료 버튼 `B`를 직접 확인.

위 화면은 노멀 조작 기준이다. 클래식 조작으로 바뀌면 버튼 대응이 달라지므로 이 앱의 대응표를 클래식 모드 표로 설명하지 않는다.

## 전체 게임 음계

사용자가 이 대화에 제공한 운지 안내 이미지의 19개 행을 직접 읽어 옮겼다. 회색 위·아래 화살표는 왼쪽 스틱, 노란 삼각형은 십자키다. 두 입력을 합산하면 스틱은 ±2반음, 십자키는 ±1반음이다. 아래는 제공된 그림에 쓰인 조합이며 가능한 대체 조합을 전부 나열한 것은 아니다. 제공 이미지는 저장소에 복제하지 않았다.

| 실음 | 게임 컨트롤러 조합 | 앱의 두 손가락 대응 |
| --- | --- | --- |

## 실물 굿즈의 운지

[HORI NSX-261 공식 설명서](https://hori.jp/image/2026/11/%E3%80%90jp%E3%80%91nsx-261_manual_261105.pdf) 3쪽의 번호 배치와 7쪽의 채움/빈 구멍 그림을 참고한다. `app/fingering.js`의 기존 25개 음계 자료를 그대로 읽는 `SCALE_GUIDE`를 제공해 표와 실제 입력의 운지 데이터가 달라지지 않도록 했다. 7쪽의 자연음·반음·전자 악기 확장 운지 그림을 다시 열어 기본 5음 및 확장 구간과 대조했다. 이 표의 오선 기보는 실음보다 한 옥타브 낮게 표기되어 앱에서는 실음 MIDI를 사용한다.

- 게임 컨트롤러 표: 낮은 시(B4)부터 높은 파(F6), 19음.
- 실물 굿즈 표: 낮은 라(A4)부터 높은 라(A6), 25음.
- 굿즈의 높은 파♯(F♯6)부터 높은 라(A6)는 전자 제품 전용 확장 운지다.
- 메뉴의 전체 음계 표에는 `음계 / 게임 버튼 조합 / 앱 기본 버튼+반음 / 실물 앞면·뒷면 운지`를 분리해서 표시할 수 있다.
- 금색 구멍=닫힘, 어두운 구멍=열림을 같은 도식으로 표시하고, 텍스트 보조로 앞면 1–10과 뒷면 11–12를 구분한다.
- 굿즈의 최저 두 음과 최상 네 음은 위 게임 컨트롤러 표의 범위 밖이므로 게임 버튼 조합을 꾸며 넣지 않는다.
