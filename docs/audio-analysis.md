# 버튼 연주와 자동 재생 — 2026-11-14

## 현재 자동 재생

모든 곡은 `OcarinaAudio.play()`를 거쳐 직접 연주 `noteOn()`과 동일한 `_createVoice()`를 사용합니다. 별도 MP3·미디어 재생 요소·원격 음원 주소는 앱에서 제거했습니다. 음량과 옥타브도 직접 연주와 같습니다.

`app/song-performance.js`는 12곡의 기존 음 시작 간격을 유지하며, 젤다의 자장가를 제외한 곡의 각 음 슬롯을 100% 속도에서 최대 350 ms로 제한합니다. 나머지 간격은 무음으로 채웁니다. 오디오 엔진은 슬롯 끝 45 ms 전에 음을 놓고 25 ms 동안 감쇠하므로 마지막 음도 약 330 ms 안에 무음이 됩니다. 허수아비 곡은 기존 600 ms 간격을 유지하면서 같은 짧은 음을 사용합니다. 연속된 같은 음도 각각 끊어서 냅니다. 속도 설정은 음과 쉼을 함께 늘리거나 줄이며 피치는 유지합니다.

이는 사용자가 인식 문제로 보고한 녹음의 허밍·옥타브 차이·긴 여운을 없애는 변경입니다. 게임 실기의 인식 성공을 직접 확인한 것은 아닙니다.

## 자장가 자동 재생 보정 (2026-11-14)

사용자는 직접 버튼 연주는 정상 인식되지만 자장가의 자동 재생은 에포나로 인식된다고 보고했습니다. 저장된 음 순서는 자장가 B5–D6–A5 반복과 일치하며, 에포나 D6–B5–A5와 구분됩니다. 이전의 일괄 350 ms 제한으로 자장가 중간 무음이 523/104/949/512/101 ms까지 생기는 것을 코드에서 확인했습니다.

자장가만 중간 음 슬롯을 다음 음 시작까지 채워 약 20 ms의 짧은 무음으로 연결했습니다. 음높이·음색·시작 박자·짧은 마지막 음은 유지합니다. 재생 속도 50/100/160%에서 연결 간격, 음 순서, 끝음 제한을 검사했습니다. 긴 무음은 확인된 재생 문제이지만 게임의 오인식 원인임을 직접 증명한 것은 아닙니다.

[닌텐도 공식 마이크 입력 안내](https://en-americas-support.nintendo.com/app/answers/detail/a_id/71860/p/1095/c/947)는 게임의 − 버튼 연습 모드에서 음높이와 음 길이의 인식 여부를 확인할 수 있다고 설명합니다. 실기 재확인이 필요하면 이 화면에서 어느 음이 다르게 잡히는지 확인할 수 있습니다.

## 과거 공식 녹음 분석 (2026-11-13)

출처는 [Nintendo 공식 악보 페이지](https://www.nintendo.com/jp/games/switch2/aa9ja/melody/index.html)가 제공하는 `assets/img/melody/melody_*.mp3`입니다. 12개 파일은 긴 편곡이 아니라 게임 입력 구절 5~8음과 잔향을 담고 있습니다. 이전 버전은 원본 녹음을 직접 스트리밍했습니다. 사용자가 허밍과 긴 끝음 때문에 인식이 실패하는 곡이 있다고 알려, 2026-11-14부터 이 경로를 제거했습니다.

이전 `app/song-performance.js`는 화면의 버튼·악보 강조를 위한 음 시작/종료 마커 74개를 저장했습니다. 현재는 음 시작 시점만 박자 간격에 사용합니다. 원본 MP3를 임시 폴더에서 24 kHz 모노 PCM으로 디코딩한 뒤 2 ms 간격 스펙트럼 플럭스, 5 ms 간격 주파수 추정, 기본 주파수의 진폭 포락선을 대조했습니다. 마커는 약 10~30 ms 수준의 추정치입니다. 음이 끝난 뒤 잔향·휴지 구간에는 강조를 끕니다. 분석에 사용한 MP3와 PCM은 저장소와 배포물에 넣지 않습니다.

2026-11-13 응답 헤더에서 `Origin: https://erist.github.io`를 보냈을 때 `Access-Control-Allow-Origin`이 없었습니다. 따라서 공식 파일을 Web Audio로 직접 fetch/decode하여 단음을 추출하는 방식은 현재의 정적 GitHub Pages 환경에서 사용할 수 없습니다. 일반 `<audio>` 스트리밍은 이와 별개로 가능합니다.

## 직접 운지 합성

직접 운지는 원본 녹음과 같다는 주장을 하지 않습니다. 원본 파일을 복제하지 않고 Web Audio 발진기로 합성합니다. 기존에는 모든 음에 동일한 강한 2차 배음을 썼지만, 다음 공개 녹음의 안정 구간에서 측정한 배음 비율을 음높이별 합성 프로필에 적용했습니다.

| 실음 | 측정 구간 | 측정 중심 주파수 | 2차/기본음 | 3차/기본음 |
| --- | --- | ---: | ---: | ---: |
| D5 | time, 0.66–0.86초 | 591.39 Hz | 0.0045 | 0.0022 |
| F5 | time, 1.76–1.96초 | 700.37 Hz | 0.0012 | 0.0041 |
| A5 | time, 0.20–0.40초 | 886.62 Hz | 0.0025 | 0.0080 |
| B5 | saria, 0.68–0.88초 | 995.90 Hz | 0.0021 | 0.0201 |
| D6 | storm, 0.56–0.76초 | 1179.19 Hz | 0.0167 | 0.0125 |

Hann 창으로 가중한 조화 성분 최소제곱 맞춤으로 1~8차 배음의 크기를 추정했습니다. 평균율의 음높이는 유지하고 배음 비율만 적용했습니다. 긴 음의 복소 복조 주파수 변화에서 D5/F5는 약 2.3 Hz·2~3센트, B5는 약 8.9 Hz·1.7센트, D6는 약 7.7 Hz·8센트의 작은 변화가 관찰되어 비브라토 프로필에 반영했습니다. A5는 안정 구간이 짧아서 3.2 Hz·2.2센트의 보수적인 합성 설정을 사용합니다.

녹음의 음색은 곡마다 다릅니다. 예를 들어 폭풍의 노래 D5 구간은 3차 배음이 기본음의 약 3배인 반면 시간의 노래 D5는 기본음이 지배적입니다. 젤다의 자장가와 에포나의 노래는 기보상의 기본 음역과 녹음 음역도 서로 다릅니다. 위 프로필은 라이브 오카리나의 근사치이며, 모든 공개 곡 또는 실기 게임 자유 연주의 파형을 동일하게 재현한다는 뜻이 아닙니다.
