## 전체 화면·직접 운지 개편 — 2026-11-13

- 오카리나를 가로 화면 전체로 확대. 악보는 왼쪽 위 빈 공간의 배경 레이어, 터치하면 전체 원본 확대. 별도 부는 버튼 제거.
- 직접 운지는 각 포인터가 닫은 구멍을 추적하고 손을 떼거나 취소하면 해제. 조합 변경에는 35ms 안정화 시간을 주고 탭 운지는 즉시 발음.
- 동시 터치 9점 이상이면 직접 운지, 미만이면 탭 운지가 기본이며 선택은 저장. 기본 5음의 필요 동시 접점 수는 9/7/5/4/2.
- 667×375·844×390 브라우저에서 전체 화면 배치, 12개 구멍, 악보 확대·메뉴·선택곡 자동재생·정지 확인. 667px 문서 가로 넘침 없음.
- 실제 브라우저에서 젤다의 자장가 6음 키 연주 완료, 음 해제 후 직접 운지 구멍 전부 열림, 콘솔 오류 없음 확인.
- 터치 모델 테스트는 9접점 D5, 손가락 해제에 따른 F5 전환, 같은 구멍의 중복 접점, 미끄러짐, 취소 및 모드 전환, 잘못된 조합의 무음을 검증.
- 현재 브라우저 자동화는 실제 다중 터치 입력을 지원하지 않아 실물 휴대폰의 9점 동시 인식은 검증하지 못했습니다. 자동화된 입력 테스트와 실제 장치 검증을 구분합니다.
- 오디오·곡·운지·입력 자동 테스트 총 34개 통과. 입력 통합 테스트 7개는 실제 앱 이벤트 처리 코드를 사용해 지연된 오디오 준비, 짧은 탭, 중복 접점 및 취소 경쟁 조건을 검증합니다.
