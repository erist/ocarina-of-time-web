# Hyrule Melody — 시간의 오카리나

휴대폰 스피커로 오카리나 선율을 연주하는 비공식 팬 웹앱. Nintendo/HORI와 제휴하지 않습니다.

배포 주소: https://erist.github.io/ocarina-of-time-web/

사용자 승인에 따라 `erist/ocarina-of-time-web` 공개 저장소와 무료 GitHub Pages로 운영합니다.

## 제공 기능

- 가로 화면 전체를 채우는 오카리나, 빈 공간에 배경처럼 표시하는 선택 악보
- 햄버거 메뉴 안에 악보 목록·설정·자료, 악보 터치 시 확대 팝업
- 숲색·금색·푸른 오카리나·양피지 악보 디자인
- HORI NSX-261 앞면 10개·뒷면 2개 버튼 위치와 운지 25음 재현
- 직접 운지(동시 터치)·탭 운지(구멍 상태 유지) 모두 별도의 부는 버튼 없이 발음, 간편 5음 및 키보드 1–5
- 12곡 이름·효과·입력 순서·자동 연주·운지 연습
- Nintendo 공식 호스트의 전체 악보 직접 표시 및 전체곡 스트리밍
- 허수아비 8음 저장·재생, 음량·속도·옥타브 조절

## 운지 입력

설정에서 직접 운지와 탭 운지를 선택합니다. 직접 운지는 손가락을 댄 구멍만 닫히며 유효한 운지 조합에서 소리가 납니다. 손을 모두 떼거나 터치가 취소되면 즉시 음을 해제합니다. 탭 운지는 구멍 상태를 유지하고 구멍을 누르는 동안 현재 조합으로 발음합니다.

공식 기본 5음 운지에는 D5 9점, F5 7점, A5 5점, B5 4점, D6 2점의 동시 터치가 필요합니다. 브라우저가 알리는 동시 터치 수가 9점 이상이면 직접 운지, 그보다 적으면 탭 운지가 기본입니다. 사용자가 고른 방식은 저장됩니다. 기기 지원 수는 설정에 표시하며 실제 손가락 인식과 시스템 제스처 간섭은 기기마다 확인이 필요합니다.

## 검증 범위와 한계

기본 직접 연주는 D5/F5/A5/B5/D6의 합성 소리입니다. 게임에서 추출한 샘플은 포함하지 않습니다. N64의 기본 발음 음역은 자료로 확인했지만 2026판 실물의 정확한 음색·음역과 Switch 2 마이크 인식은 측정하지 않았습니다. 설정에서 옥타브를 조절할 수 있습니다.

입력 구절 자동 재생은 균등한 박자로 입력 순서를 안내합니다. 원곡의 전체 연주와 리듬은 공식 전체곡 듣기에서 확인할 수 있습니다. 실제 게임에서는 이미 습득한 곡만 인식됩니다.

공식 악보·음원은 Nintendo 호스트의 공개 URL을 직접 참조합니다. 해당 파일은 저장소에 복제하지 않으며 권리는 원 권리자에게 있습니다. 네트워크나 원본 제공 상태에 따라 이용이 제한될 수 있습니다. 원문 링크를 함께 제공합니다.

## 로컬 실행

Node.js 22 이상, 별도 설치 의존성 없음.

```sh
npm run dev
npm test
npm run build
```

미리보기: `http://127.0.0.1:4173`. 빌드 결과: `dist/`. `app/` 자체도 정적 호스팅 가능합니다.

GitHub Pages는 `gh-pages` 브랜치 루트를 제공합니다. 수정 후 테스트하고 `app/`의 새 상태를 해당 브랜치로 배포합니다.

근거: [자료 출처와 검증 한계](docs/sources.md).
