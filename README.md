# Hyrule Melody — 시간의 오카리나

휴대폰 스피커로 오카리나 선율을 연주하는 비공식 팬 웹앱. Nintendo/HORI와 제휴하지 않습니다.

배포 주소: https://erist.github.io/ocarina-of-time-web/

사용자 승인에 따라 `erist/ocarina-of-time-web` 공개 저장소와 무료 GitHub Pages로 운영합니다.

## 제공 기능

- 가로 화면 전체를 채우는 오카리나, 빈 공간에 배경처럼 표시하는 선택 악보
- 햄버거 메뉴 안에 악보 목록·설정·음계와 운지·자료, 악보 터치 시 확대 팝업
- 숲색·금색·푸른 오카리나·양피지 악보 디자인
- HORI NSX-261 앞면 10개·뒷면 2개 버튼 위치와 운지 25음 재현
- 최대 두 접점으로 게임 19음 연주, L/R/A/Y/X 표기와 B 정지
- 세로 회전 잠금을 유지한 채 앱 화면·메뉴만 좌우 90° 회전
- 공식 12구멍의 직접·탭 운지와 기본 5음 버튼도 선택 가능
- 12곡 이름·효과·입력 순서·자동 연주·운지 연습
- Nintendo 공식 호스트의 전체 악보 표시 및 짧은 입력 구절의 원본 녹음 스트리밍
- 허수아비 8음 저장·재생, 음량·속도·옥타브 조절

## 운지 입력

기본은 두 손가락 모드입니다. 한 손가락으로 L/R/A/Y/X 기본음을 누르고, 다른 손가락으로 −3부터 +3까지 반음 조절 영역을 터치하거나 미끄러뜨립니다. 낮은 시(B4)부터 높은 파(F6)까지 19음을 모두 최대 두 접점으로 냅니다. 기본음 손가락을 떼면 멈추고, 보정 손가락만 떼면 기본음으로 돌아갑니다. B는 정지입니다. 키보드는 L/R/A/Y/X 또는 1–5, B로 정지할 수 있습니다.

이는 휴대폰을 위한 대체 운지입니다. 실제 악기의 12구멍을 동일한 손가락 수로 막는 방법과는 구별합니다. 메뉴의 음계표는 컨트롤러 조합, 두 손가락 조합, 실물 운지 그림을 함께 제공합니다. 범위 밖의 굿즈 6음도 펼쳐서 확인할 수 있습니다.

설정의 화면 방향은 세로 화면에서 앱과 메뉴만 ±90° 돌립니다. 운영체제의 회전 잠금을 바꾸지 않으며, 이미 가로인 화면에서는 중복 회전하지 않습니다. 공식 12구멍 모드는 누르는 동안 닫힘 또는 탭해서 상태 유지 중 선택합니다. 직접 운지는 기본 5음에도 최대 9접점이 필요해 기기의 터치 한계 영향을 받습니다.

## 소리와 검증 범위

12곡 재생은 별도의 원곡 듣기 버튼 없이 Nintendo 공식 녹음을 사용합니다. 100% 속도에서 녹음의 음색과 박자가 유지됩니다. 화면의 음표 강조는 녹음 시간에 맞춘 표시용 마커입니다. 사용자 지정 허수아비 곡은 합성으로 재생합니다.

직접 운지음은 공식 공개 녹음의 배음·비브라토를 분석해 조정한 합성음이며 원본과 완전히 같지 않습니다. 평균율의 음높이를 사용하고, 설정에서 옥타브를 바꿀 수 있습니다. 실물 휴대폰과 Switch 2의 마이크 인식은 직접 검증하지 못했습니다.

공식 로고·악보·음원은 Nintendo 호스트의 공개 URL을 참조합니다. 해당 파일을 저장소에 복제하지 않습니다. 네트워크나 원본 제공 상태에 따라 이용이 제한될 수 있으며 권리는 원 권리자에게 있습니다.

## 로컬 실행

Node.js 22 이상, 별도 설치 의존성 없음.

```sh
npm run dev
npm test
npm run build
```

미리보기: `http://127.0.0.1:4173`. 빌드 결과: `dist/`. `app/` 자체도 정적 호스팅 가능합니다.

GitHub Pages는 `gh-pages` 브랜치 루트를 제공합니다. 수정 후 테스트하고 `app/`의 새 상태를 해당 브랜치로 배포합니다.
