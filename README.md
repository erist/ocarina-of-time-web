# Hyrule Melody — 시간의 오카리나

휴대폰 스피커로 오카리나 선율을 연주하는 비공식 팬 웹앱. Nintendo/HORI와 제휴하지 않습니다.

배포 주소: https://erist.github.io/ocarina-of-time-web/

사용자 승인에 따라 `erist/ocarina-of-time-web` 공개 저장소와 무료 GitHub Pages로 운영합니다.

## 제공 기능

- 가로 화면 전체를 채우는 오카리나, 빈 공간에 배경처럼 표시하는 선택 악보
- 햄버거 메뉴 안에 악보 목록·설정·음계와 운지·자료, 악보 터치 시 확대 팝업
- 숲색·금색·푸른 오카리나·양피지 악보 디자인
- HORI NSX-261 앞면 10개·뒷면 2개 버튼 위치와 운지 25음 재현
- 최대 두 접점으로 게임 19음 연주, L/R/A/Y/X 표기와 키보드 B 정지
- 세로 회전 잠금을 유지한 채 앱 화면·메뉴만 좌우 90° 회전
- 공식 12구멍의 직접·탭 운지와 기본 5음 버튼도 선택 가능
- 12곡의 짧은 게임 입력 구절 재생, 풀버전 오카리나 독주, 운지 연습
- Nintendo 공식 호스트의 전체 악보 표시, 버튼과 같은 합성음으로 자동 연주
- 허수아비의 노래 5~8음 자동 저장·재생, 음량·속도·옥타브 조절

## 운지 입력

기본은 두 손가락 모드입니다. 한 손가락으로 L/R/A/Y/X 기본음을 누르고, 다른 손가락으로 −3부터 +3까지 반음 조절 영역을 터치하거나 미끄러뜨립니다. 낮은 시(B4)부터 높은 파(F6)까지 19음을 모두 최대 두 접점으로 냅니다. 기본음 손가락을 떼면 멈추고, 보정 손가락만 떼면 기본음으로 돌아갑니다. 키보드 B는 정지입니다. 키보드는 L/R/A/Y/X 또는 1–5, B로 정지할 수 있습니다.

이는 휴대폰을 위한 대체 운지입니다. 실제 악기의 12구멍을 동일한 손가락 수로 막는 방법과는 구별합니다. 메뉴의 음계표는 컨트롤러 조합, 두 손가락 조합, 실물 운지 그림을 함께 제공합니다. 범위 밖의 굿즈 6음도 펼쳐서 확인할 수 있습니다.

화면 방향의 기본값은 **브라우저 방향 그대로**입니다. 세로에서는 악보 아래에 오카리나가 놓이고, 가로에서는 왼쪽에 악보, 오른쪽에 오카리나가 놓입니다. 세로 회전 잠금 상태로 가로로 연주하려면 설정에서 좌우 회전 방향을 선택하세요. 저장된 방향은 다음 방문에도 유지됩니다.

웹앱으로 추가하려면 오른쪽 위 햄버거 메뉴 옆의 **ⓘ**를 누르세요. 기기와 브라우저에 맞는 추가 방법을 확인할 수 있습니다.

공식 12구멍 모드는 누르는 동안 닫힘 또는 탭해서 상태 유지 중 선택합니다. 직접 운지는 기본 5음에도 최대 9접점이 필요해 기기의 터치 한계 영향을 받습니다.

## 소리와 검증 범위

12곡과 허수아비 곡은 버튼 연주와 같은 합성음·음량·옥타브로 재생합니다. 기본 속도(100%)에서 짧은 구절 12곡의 음 시작 간격은 닌텐도 공식 연주에서 측정한 값을 따릅니다. 시간의 노래와 에포나의 노래는 각 음을 유지하는 시간과 음 사이의 쉼도 공식 연주에 맞췄습니다. 젤다의 자장가는 중간 음을 다음 음 직전까지 이어 불고, 나머지 곡은 짧은 음과 쉼을 사용합니다. 재생 속도를 바꾸면 음높이는 유지되고 음과 쉼의 길이가 함께 조절됩니다.

곡 목록이나 연주 화면에서 **음표와 재생 삼각형이 함께 그려진 버튼**을 누르면 전체 선율을 독주로 들을 수 있습니다. 젤다의 자장가, 에포나의 노래, 사리아의 노래, 시간의 노래, 폭풍의 노래는 각 선율이 등장하는 배경음악을 한 차례 연주합니다. 태양의 노래는 마지막 상승 음형까지, 워프 6곡은 부름과 응답에서 마지막 음까지 연주합니다. 허수아비의 노래는 다섯 번째 음부터 이 브라우저에 자동 저장되며, 입력한 순서대로 재생됩니다.

직접 운지음은 공식 공개 녹음의 배음·비브라토를 분석해 조정한 합성음이며 원본과 완전히 같지 않습니다. 평균율의 음높이를 사용하고, 설정에서 옥타브를 바꿀 수 있습니다. 실물 휴대폰과 Switch 2의 마이크 인식은 직접 검증하지 못했습니다.

공식 로고·악보는 Nintendo 호스트의 공개 URL을 참조합니다. 해당 파일을 저장소에 복제하지 않습니다. 네트워크나 원본 제공 상태에 따라 이용이 제한될 수 있으며 권리는 원 권리자에게 있습니다.

## 로컬 실행

Node.js 22 이상, 별도 설치 의존성 없음.

```sh
npm run dev
npm test
npm run build
```

미리보기: `http://127.0.0.1:4173`. 빌드 결과: `dist/`. `app/` 자체도 정적 호스팅 가능합니다.

GitHub Pages는 `gh-pages` 브랜치 루트를 제공합니다. 수정 후 테스트하고 `app/`의 새 상태를 해당 브랜치로 배포합니다.

근거: [자료 출처와 검증 한계](docs/sources.md).

## 모바일 설정과 방문 통계

설정의 언어 항목에서 한국어, English, 日本語 중 하나를 선택할 수 있습니다. 선택은 이 브라우저에 저장됩니다. 공식 도안과 악보 이미지는 원본으로 표시합니다. 소리가 나지 않으면 같은 설정에서 **소리 다시 연결**을 눌러 저장된 음량으로 짧은 시험음을 재생할 수 있습니다.

운영자는 개인 Google 계정으로 [사이트 방문 통계](https://console.firebase.google.com/project/erist-ocarina-visits/firestore/databases/-default-/data/~2Fsites~2Focarina)를 열어 2026년 11월 15일 배포 이후의 누적 집계를 확인할 수 있습니다. 문서 위치는 `sites → ocarina`입니다.

| 누적 지표 | 사이트 전체 | 인스타그램 유입 |
| --- | --- | --- |
| 페이지를 연 횟수 (새로고침 포함) | `pageViews` | `instagramViews` |
| 방문 횟수 | `visits` | `instagramVisits` |
| 방문한 브라우저 수 (추정) | `visitors` | `instagramVisitors` |

인스타그램 프로필과 스토리에는 [인스타그램 공유용 링크](https://erist.github.io/ocarina-of-time-web/?utm_source=instagram&utm_medium=social)를 사용하세요. 일반 주소에서도 브라우저가 인스타그램 출처를 전달하면 집계합니다. 공유용 링크를 다른 곳에 다시 올려도 해당 링크는 인스타그램 유입으로 기록됩니다.

같은 브라우저에서 30분 이내에 다시 열면 한 번의 방문으로 묶습니다. 인스타그램 유입 여부가 바뀌면 새 방문으로 셉니다. 기기·브라우저를 바꾸거나 저장 정보를 지우면 새 방문자로 집계될 수 있습니다. 브라우저에는 이전 방문 여부와 마지막 방문 시각을 저장하고 서버에는 합계만 더합니다. 브라우저에서 추적 거부 또는 GPC를 설정하면 집계에서 제외합니다.

결제 계정 없이 Firestore 무료 할당량을 사용합니다. 페이지를 열 때 문서 쓰기 1회를 사용하며, 일일 20,000회 한도를 초과한 동안의 방문은 누락될 수 있습니다. [Firestore 무료 할당량](https://firebase.google.com/docs/firestore/quotas)
